# CubeWright AI Promotion for A-to-Z Mod Descriptions

Use this consistent section across every mod listing. Place it near the end of the description, before requirements, credits, or technical notes.

## Recommended website concept

**Name:** CubeWright AI  
**Tagline:** Describe it. CubeWright builds it.  
**Positioning:** An AI development assistant that turns plain-language Minecraft mod ideas into structured projects and guides users through building, testing, and fixing them.

**Website:** https://devxkamlesh.com/cubewright  
This uses the existing `devxkamlesh.com` domain, so a separate domain purchase is not required.

## Suggested landing page

1. **Hero:** “Build Minecraft mods by describing your idea.”
2. **Idea box:** Large prompt field with examples such as a custom ore, boss, biome, or inventory feature.
3. **Project choices:** Minecraft version, Fabric/NeoForge, Java version, and project name.
4. **Agent plan:** Show generated features and files before code generation.
5. **Build workspace:** Code preview, build output, error-fixing chat, and downloadable project ZIP.
6. **Safe expectations:** State that generated projects require testing and that users own responsibility for publishing and third-party assets.
7. **Waitlist:** Email or social follow option for launch updates.
